# Prepared before the event

The organisers allowed pre-written code. The first commit of this repository is that preparation, committed at the time the team imported it. It contains:

* the agent graph, verifier, tools, API, UI, rule base, synthetic registry and a 30-case evaluation set, with 42 passing tests;
* these items were **not** done before the event and are done in the hackathon, with their commits and pull requests: running with the real local model (Qwen3), verifying rule quotes against the official sources, reading real phone photos, extending and relabelling the evaluation cases with a second reviewer, UI changes after real use, bug fixes, and the demo.

Everything committed after the first commit is event work by the named authors.
